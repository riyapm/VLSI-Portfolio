## 📁 Project Details

### 1. AHB-APB Bridge
📂 [`ahb-apb-bridge/`](./ahb-apb-bridge)

Designed and verified a full-functional AHB-to-APB protocol bridge enabling communication between a high-speed AHB bus and low-power APB peripherals.

- Implemented in Verilog with complete FSM-based control logic
- Developed a comprehensive testbench from scratch with complex test cases
- Achieved **100% functional coverage**
- Design verified and ready for synthesis

**Tools:** Verilog, ModelSim  
**Skills:** RTL Design, Testbench Development, Functional Verification

---

### 2. AHB Slave
📂 [`ahb-slave/`](./ahb-slave)

Designed an AHB-compliant slave module to interface with the AHB-APB bridge, implementing the AMBA AHB protocol specification for slave-side transactions.

**Tools:** Verilog, ModelSim  
**Skills:** RTL Design, AMBA Protocol

---

### 3. AES-256 RTL
📂 [`aes-256-rtl/`](./aes-256-rtl)

RTL implementation of the AES-256 encryption algorithm in Verilog. Covers the full encryption pipeline including key expansion, SubBytes, ShiftRows, MixColumns, and AddRoundKey operations.

**Tools:** Verilog, ModelSim  
**Skills:** RTL Design, Digital Cryptography, Pipelining

**Skills:** Full-Custom Layout, DRC/LVS, Area Optimization
